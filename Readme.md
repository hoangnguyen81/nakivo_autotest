Setup Environment
To run this project, please make sure to have the following installed:

Java JDK 17
Download and install from: Oracle Java JDK 17

Apache Maven
Instructions available at: https://maven.apache.org/install.html

Allure Report (if needed for generating reports)
Follow the steps here: https://allurereport.org/docs/install/

Run test with: mvn clean test
